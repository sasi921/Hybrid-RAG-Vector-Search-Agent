🚀 Built a Hybrid RAG Vector Search Agent — beyond simple keyword lookup.

It ingests Markdown/TXT files, persists chunks in SQLite, combines FTS5/BM25 keyword ranking with vector similarity, and fuses results using Reciprocal Rank Fusion. Every response includes source citations.

It ships with automated tests, an evaluation dataset, GitHub Actions CI, and an optional local neural embedding model. The default mode works offline without API keys.
